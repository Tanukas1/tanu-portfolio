# tanu-portfolio

Tanu Kashyap — Full-Stack Developer Portfolio built with Next.js (App Router), React 19, TypeScript, and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
